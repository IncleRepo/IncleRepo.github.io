# Dev Archive

Dev Archive는 백엔드 개발 과정에서 학습한 개념과 설계 판단을 기록하는 개인 기술 블로그입니다.

단순한 사용법보다 기술이 동작하는 원리, 해결하려는 문제, 적용 조건과 트레이드오프를 이해하는 데 초점을 둡니다.

## 주요 주제

- Java와 Spring
- 소프트웨어 아키텍처와 모듈 설계
- REST API와 애플리케이션 보안
- 데이터베이스와 데이터 접근 기술
- 비동기 처리와 외부 시스템 연동
- 테스트, 성능과 운영 안정성

## 운영 방식

모든 글은 Markdown으로 작성하고 Git으로 변경 이력을 관리합니다. Hugo로 정적 사이트를 생성하고 GitHub Pages를 통해 게시합니다.
